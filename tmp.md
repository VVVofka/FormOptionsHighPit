# Добавление % от общего количества в SDGP
Надо добавить новое поле в таблицу
- Является мерой части количества непустых ячеек приходящейся на запись в %
- тип - float
- расположение - справа от Colors
- Примеры представления в таблице:
    "RGB 30%;" целое значение 
    "R 39.12%;" нецелое (отображать только 2 знака)
    "N;" (для N всегда = 0)
    "G;" (если = 0) 
- Сумма для всех записей после нормировки = 100%
- Нормировку производить автоматически, с отображением в элементах управления при:
    открытии
    нажатии кнопок Check, Save, Save As
    закрытии формы,
нормировка прежде основного действия.
- если поле пустое, то = 0
- когда все = 0, то 100 / количество записей
- Поле становится недоступным и = 0, когда Colors = N
- Обновить шаблоны: 1 запись = 100%, 2 записи = 50% + 50%
