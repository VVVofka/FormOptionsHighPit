# Доработка вкладки Gener основной формы

## Основное

- Замена части интерфейса вкладки вызовом формы SDGP (start data generation parameters)
- Добавить кнопку Generation
- Добавить предпросмотр

### Замена части интерфейса вкладки вызовом формы SDGP
- Разделить вкладку на 2 области по горизонтали
- сместить поле size влево, вплотную к надписи "Field side size:"
- Удалить группу Points
- Удалить группу Initial points placement
- перенести size в левую область
- Добавить в левую часть:
    - поле с % заполнения поверхности непустыми точками. 2 знака после запятой, с удалением незначящих 0. По умолчанию = 7%
    - поле инициализации генератора случайных чисел. Целое. Если 0 - инициализация от таймера. >0 - каждый запуск Generation - инициализация этим числом. <0 - инициализация при первом запуске, или при изменении параметров генерации.
    - поле с информацией от SDGP, многострочная, только для чтения, как в списке SDGP. Полосы прокрутки.
    - кнопку Edit для него - открыть SDGP. 
    - кнопку Generation. Пока только для uniform без области - равномерно заполнить квадрат.
- Добавить в правую часть поле с рисунком, пока чёрный квадрат размером 256*256

# 3
1. По закрытию SDGP не происходит передача обновлённых данных (или не отображаются в поле Start data)
2. Расширь функциональность seed:
    Если число отрицательно, то в первый раз после выбора вкладки Gener происходит инициализация им (со знаком +), в последующем как с 0. Само число в поле не меняется.
3. При нажатии Generation заметна задержка. Чем вызвана расчёт точек или вывод графики на экран?
4. Учитываются ли при генерации случаи попадания разных точек в одно и то же поле. Так быть не должно. Возможно при большом количестве точек время будет большим. Ограничь 3 секундами.
5. Создай StatusBar в низу формы. Выводи туда разную информацию. Например при Generation: количество сгенерированных точек по цветам и общее. Сообщение об ошибках или timeout.

# 4
1. Сохрани в настройках программы последнюю активную вкладку. При следующем запуске программы активируй её.
2. Обработай Region пока только для Uniform:
    - Для прямоугольника:
        - x, y - координаты середины прямоугольника,
        от -1.0 - левый край до +1.0 - правый край
        - w, h - ширина и высота, от 0 до 2.0
    - Для круга:
        - x, y - координаты середины,
        от -1.0 - левый край до +1.0 - правый край
        - r от 0 до 1.0
    - Поле - тор, поэтому возможны переносы на другую сторону.
    - В SDGP поле Percent может содержать значение -1%. Это значит "сколько получится". Работает только когда задан Region. Сплошное заполнение этого региона. Эти точки не учитываются в общем подсчёте и нормировке. Т.е. если таблица содержит записи только с -1%, то поле Fill % в основной форме игнорируется - вывести сообщение об этом в statusbar.
    - При нескольких записях заполняются последовательно. Если регионы перекрываются, точки поздней записи не могут перекрывать раннюю.
    Исключение - "цвет" N. Это пустая ячейка - может стирать ячейки установленные записями с Percent = -1%. Например можно нарисовать сплошной круг, потом "нарисовать" внутри круг меньшего размера с "цветом" N - получится окружность.
