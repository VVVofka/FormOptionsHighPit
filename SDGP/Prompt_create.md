# Цель

Нужна программа на питон для создания, редактирования и сохранения настроек.
Может работать как самостоятельно, так и вызываться из внешней программы.


# Данные

Таблица с небольшим числом записей, без оптимизаций и индексирования. Порядок записей имеет значение. Может храниться в файле формата json с расширением sdgp. 
Поля записи:
1. Colors - текстовое, одно из значений RGB R G B RG GB BR N
2. Region - текстовое, может быть пустым или содержать от 2 до 4 значений с плавающей точкой:
	- 2 значения: координаты xy
	- 3 значения: координаты xy, размер w = h = 1.0
	- 4 значения: координаты xy, размеры wh
x,y - [-1.0; +1.0] default = 0
w, h - (0; +1.0] default = 1
Длина поля < 64 символов.
3. Parameters - текстовое поле от пустого до 256 знаков произвольного содержания. По умолчанию пустое.


# Самостоятельное приложение

Есть собственный конфигурационный файл где:
	- Запоминает последний открытый файл. 
	- Хранит несколько шаблонов.
При запуске без параметров открывает последний открытый файл.
Если файл не существует, открывает диалог открытия файла. Если пользователь ввёл имя несуществующего, предлагает выбрать шаблон.

Приложение может иметь аргумент в командной строке - имя файла для открытия или с ключом -t - имя шаблона.


# Как внешний модуль

Содержит функции:
- OpenDlg() - запуск как самостоятельное приложение
- OpenFile(file name) - запуск формы с конкретным файлом
- OpenData(data) - отображение переданных данных для модификации, сохранения и т.д.
Все функции возвращают новые данные.


# Макет

Три области по вертикали:
1. Область управления файлами
2. Область ввода и отображения
3. Область управления


## Область управления файлами

1. Имя файла (только чтение); 
2. Кнопка открытия файла справа

## Область ввода и отображения

Две области по горизонтали:

### Область ввода

	1. Выпадающий список с Colors
	2. Текстовое поле Region
	3. Текстовое поле с прокруткой Parameters

### Область таблицы

	1. Список с записями. Есть полоса прокрутки
	2. Кнопки управления для текущей записи - удаление, перемещение вверх/вниз

## Область управления

	Кнопки в ряд по горизонтали:
	1. Кнопка Check
	2. Кнопка Save
	3. Кнопка Save as
	4. Кнопка Cancel
	5. Кнопка Close

# Примечания

## Формат Region

- разделитель значений - пробел (может быть несколько подряд)
- В каждом значении важны только цифры, знаки, десятичные разделители (может быть и "." и ","). Остальное игнорируется.
- Парсинг на вещественные числа.
- При проверке проверять число значений и диапазон значений (см. раздел
# Данные).

## Формат списка

Каждый элемент списка - 1 строка в формате
"[Colors]; x:### y:### w:### h:###; [Parameters]"

x y w h - округлены до целого
Parameters - сколько поместится

При ошибке парсинга писать "#err"

## Управление

При инициализации выделяется последняя запись.
При изменении выбранной записи и инициализации - автоматически изменяются поля ввода.
При загрузке и перед Save, Save as сделать проверку Region. При ошибках выдать сообщение пользователю.
После "Save", "Save as" обновить список.
Кнопка Cancel - отменить несохранённые изменения (заново перечитать файл)
При ошибке парсинга Colors - установить в RGB без предупреждения.
При закрытии формы при не сохранённых данных предложить сохранение пользователю.

## Шаблоны

1. Uniform
	- RGB
	- ""
	- ""
2. Normal
	- RGB
	- ""
	- "0.9 1.2"
3. Zones
	First record
		- BR
		- "-0.3 0 0.4"
		- ""
	Second record
		- G
		- "0.3 0.2 0.45"
		- "0.85 0.8 0.9 0.75"
